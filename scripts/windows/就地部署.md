# Windows 就地部署（不使用 Docker）

本目录参考 `llm-gateway/scripts/windows` 的 WinSW 服务脚本，为 ProxySQL Admin UI 提供 Windows 发布、安装和服务管理。

## 依赖

- Windows x64
- PowerShell 7（`pwsh.exe`）
- .NET 8 SDK
- 可访问 ProxySQL Admin 端口的网络

WinSW 2.12.0 会在首次运行时从官方 GitHub Release 下载，并校验 SHA-256。下载后的 `ProxySQL-Admin-UI.exe` 是本地部署文件，不提交到 Git。

## 首次部署

在管理员 PowerShell 中，从仓库根目录执行：

```powershell
.\scripts\windows\deploy-inplace.ps1 `
  -ProxySqlConnectionString 'Server=127.0.0.1;Port=6032;Uid=admin;Pwd=CHANGE_ME;ConnectionReset=False;Pooling=True;ConnectionLifeTime=3000000;'
```

也可以双击 `就地部署.bat`，但首次部署仍需在命令行传入连接串：

```powershell
.\scripts\windows\就地部署.bat -ProxySqlConnectionString 'Server=127.0.0.1;Port=6032;Uid=admin;Pwd=CHANGE_ME;ConnectionReset=False;Pooling=True;ConnectionLifeTime=3000000;'
```

首次部署时：

1. 根据 `ProxySQL-Admin-UI.xml.example` 创建本地 `ProxySQL-Admin-UI.xml`。
2. 未传 `-AdminPassword` 时生成随机 Web 管理员密码并打印一次。
3. 执行 `dotnet publish -c Release -r win-x64` 到 `publish.staging`。
4. 短暂停止已有服务，将 staging 切换到 `publish`。
5. 首次安装 WinSW 服务；重复部署只停止、替换程序、再启动。
6. 等待 `http://127.0.0.1:8000/health` 返回 200。

如需指定 Web 初始管理员密码：

```powershell
.\scripts\windows\deploy-inplace.ps1 `
  -ProxySqlConnectionString 'Server=127.0.0.1;Port=6032;Uid=admin;Pwd=CHANGE_ME;' `
  -AdminPassword 'Use-A-Strong-Password'
```

> `DefaultUsers` 只在身份数据库中不存在该用户时创建管理员。若 `data\db\app.db` 已存在，修改 XML 中的初始密码不会重置现有账号密码。

## 为什么不需要备份脚本

程序发布目录与持久数据分离：

- `publish\`：可替换的应用程序文件
- `data\db\app.db`：Web 登录账号和身份数据
- `logs\`：WinSW 日志
- `scripts\windows\ProxySQL-Admin-UI.xml`：本地服务配置和凭据

重复部署只替换 `publish\`，不会删除或覆盖 `data\`，因此未复制 `llm-gateway` 的备份/恢复脚本。正式环境仍应按组织策略备份 `data\` 与本地 XML。

## 服务管理

可双击以下批处理文件：

| 操作 | 文件 |
|---|---|
| 一键发布并部署 | `就地部署.bat` |
| 安装服务 | `安装服务.bat` |
| 启动服务 | `启动服务.bat` |
| 停止服务 | `停止服务.bat` |
| 重启服务 | `重启服务.bat` |
| 卸载服务 | `卸载服务.bat` |

卸载服务不会删除 `publish\`、`data\`、`logs\` 或本地 XML。

## 配置

本地服务配置：

```text
scripts\windows\ProxySQL-Admin-UI.xml
```

该文件包含 ProxySQL Admin 连接串和初始 Web 管理员密码，已加入 `.gitignore`。不要提交、同步或公开它。

修改 XML 后执行：

```powershell
.\scripts\windows\restart-service.ps1
```

默认监听：

```text
http://0.0.0.0:8000
```

## 日志

日志写入仓库根目录的 `logs\`，按 10 MB 轮转并保留 8 个文件：

```text
logs\ProxySQL-Admin-UI.out.log
logs\ProxySQL-Admin-UI.err.log
```

## 安全说明

此应用可以修改 ProxySQL 运行配置并保存到磁盘。生产环境必须：

- 限制 8000 端口访问来源；
- 使用专用 ProxySQL Admin 账号；
- 使用强 Web 管理员密码；
- 在变更前核对 Runtime 与 Disk 配置并准备回滚语句；
- 不把真实连接串或密码提交到 Git。
